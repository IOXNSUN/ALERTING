🔐 Система мониторинга и алертинга инфраструктуры
Prometheus + Grafana + Alertmanager + Blackbox Exporter

🎯 Цель проекта
Создание полноценной системы мониторинга для автоматического отслеживания доступности веб-сервисов, состояния серверов и оповещения инженеров о критических событиях через Telegram.

🚀 Основные возможности
1. Мониторинг доступности веб-сайтов
Автоматическая проверка доступности сайтов и callback-URL

Мониторинг HTTP-статусов (200, 4xx, 5xx)

Отслеживание времени ответа сервера

Проверка SSL-сертификатов с расчетом оставшихся дней действия

2. Системные метрики серверов
Raspberry Pi 4 (локальный сервер мониторинга):

Загрузка CPU (ядро, iowait, user, system)

Использование RAM и SWAP

Температура процессора (критично для RPi)

Свободное место на SD-карте

Сетевой трафик и ошибки

Внешний хостинг (Hostkey, Ubuntu 24.04):

Аналогичный набор метрик

Мониторинг Docker-контейнеров

3. Алертинг в Telegram
Мгновенные уведомления о проблемах

Автоматическое восстановление (resolved)

Группировка алертов для предотвращения спама

Повторные уведомления с настраиваемым интервалом

Статусы "НЕ РАБОТАЕТ" / "ДОСТУПНО" на русском языке

4. SSL-мониторинг
Автоматическое извлечение даты истечения сертификатов

Расчет оставшихся дней до истечения

Раннее оповещение (за 30 дней до истечения)

Поддержка кастомных портов (443, 8443 и др.)

📊 Настроенные алерты
🔴 Критичные алерты (немедленное реагирование)
1. Сайт недоступен
yaml
- alert: SiteDown
  expr: probe_success{instance="https://tda-photo.ru"} == 0
  for: 1m
  annotations:
    summary: "🔴 Сайт tda-photo.ru недоступен"
    description: "Сайт не отвечает больше 1 минуты"
Действие: Проверить веб-сервер, Nginx, Flask приложение

2. Тестер недоступен
yaml
- alert: TesterDown
  expr: probe_success{instance="http://172.17.0.1:8081"} == 0
  for: 1m
  annotations:
    summary: "🔴 Тестер недоступен"
    description: "Тестер на порту 8081 не отвечает больше 1 минуты"
Действие: Проверить Docker-контейнер тестера

3. Хостинг недоступен
yaml
- alert: HostkeyDown
  expr: probe_success{instance="151.241.227.34"} == 0
  for: 1m
  annotations:
    summary: "🔴 Хостинг недоступен"
    description: "Сервер 151.241.227.34 не отвечает на ping"
🟠 Алерты производительности
4. Высокая загрузка CPU (хостинг)
yaml
- alert: HostkeyHighCPU
  expr: 100 - (avg by(instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) > 80
  for: 5m
  annotations:
    summary: "🟠 Высокая загрузка CPU на хостинге"
    description: "CPU загружен на {{ $value }}%"
5. Мало места на диске (хостинг)
yaml
- alert: HostkeyLowDisk
  expr: (node_filesystem_avail_bytes{mountpoint="/"} / node_filesystem_size_bytes{mountpoint="/"}) * 100 < 10
  for: 5m
  annotations:
    summary: "🟠 Мало места на диске хостинга"
    description: "Осталось {{ $value }}% свободного места"
6. Высокая температура Raspberry Pi
yaml
- alert: RPiHighTemp
  expr: node_hwmon_temp_celsius > 75
  for: 5m
  annotations:
    summary: "🟠 Высокая температура Raspberry Pi"
    description: "Температура: {{ $value }}°C"
🟢 Информационные алерты
7. SSL сертификат скоро истечет
yaml
- alert: SSLCertificateExpiring
  expr: probe_ssl_earliest_cert_expiry - time() < 14 * 24 * 3600
  for: 1h
  annotations:
    summary: "🟡 SSL сертификат скоро истечет"
    description: "Сертификат для {{ $labels.instance }} истекает через {{ $value | humanizeDuration }}"

📈 Дашборды Grafana
1. Node Exporter Full (ID: 1860)
Назначение: Детальный мониторинг серверов

Отображаемые метрики:

CPU: загрузка по ядрам, iowait, user, system

Memory: RAM usage, SWAP, cache/buffer

Disk: использованное место, I/O операции

Network: входящий/исходящий трафик

Temperature: температура RPi

Uptime: время работы сервера

Переменные:

job: выбор источника (raspberrypi / hostkey)

instance: выбор конкретного сервера

2. Website monitoring (ID: 13041)
Назначение: Мониторинг доступности веб-сайтов

Отображаемые метрики:

HTTP status codes: 200 OK / 4xx / 5xx

Response time: время ответа сервера

SSL expiry: оставшиеся дни действия сертификатов

Availability: процент доступности за период

3. Raspberry Pi Monitoring (ID: 10579)
Назначение: Специализированный дашборд для RPi

Температура процессора

Частота CPU

Напряжение питания

Throttling status
